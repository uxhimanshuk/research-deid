research-deid

Strip names, emails, phone numbers and organisations out of interview transcripts before they go anywhere else — an LLM, a shared drive, a slide. Pseudonyms stay consistent, so the transcript is still analysable afterwards.

Runs entirely in this tab · no network

01  Load transcripts

    02  Review every replacement

    Nothing is replaced until you say so. Confident matches are pre-selected; weak guesses are listed unselected so you decide rather than find out later. Give two entries the same label to merge them into one person.

    The key maps each pseudonym back to the real value. It is the one file that can
    undo this. Keep it somewhere the transcripts are not.
  
    

    


    
  
    What this will not catch
    
  
      
  
      
    This is a first pass that removes the obvious and the repetitive, not a
    compliance control. Read the result before you trust it — and if the transcript
    covers something sensitive enough that a miss would harm someone, read it twice.
